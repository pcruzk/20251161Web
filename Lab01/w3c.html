SVG

SVG significa Scalable Vector Graphics. Es un formato utilizado para representar gráficos vectoriales en la web.

Una de sus principales ventajas es que los gráficos pueden escalarse sin perder calidad. SVG utiliza XML para representar los elementos gráficos.
